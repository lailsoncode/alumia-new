# Prompts de produção — Alumia chibi v1

As duas imagens foram criadas com a ferramenta integrada de geração de imagens, usando os arquivos indicados como referências de identidade.

## Model sheet

**Referência:** `reference-icon.png`

```text
Use case: stylized-concept
Asset type: canonical character model sheet for a mobile wellness app mascot
Input images: Image 1 is the identity reference for Alumia; preserve her facial identity, warm medium-brown skin, dark rounded curly bob silhouette, thick dark eyebrows, large round golden-brown glasses, gentle smile, coral-orange shirt, and glowing yellow flower motif.
Primary request: redesign Alumia as an original polished 2D chibi character suitable for a friendly animated app companion. Create one clean model sheet showing the exact same character consistently in six panels: full-body front neutral pose, full-body three-quarter welcoming pose, full-body side profile, full-body back view, close-up listening expression, close-up gentle celebration expression.
Subject: one adult feminine chibi mascot, approximately 3 heads tall, slightly oversized head, short simple limbs, expressive hands, stable recognizable silhouette. Core outfit is a coral-orange short-sleeve shirt, high-waisted muted teal trousers, simple warm cream sneakers, round golden-brown glasses. The small glowing flower may appear only in the welcoming and celebration panels.
Style/medium: clean premium 2D vector-like character design, rounded shapes, restrained soft cel shading, consistent line weight, animation-ready forms; distinct from 3D clay and distinct from painterly storybook art.
Composition/framing: landscape model sheet, evenly spaced panels, every full body fully visible with generous margin, neutral eye-level views, no overlapping poses.
Scene/backdrop: flat warm off-white background with very faint panel separators.
Lighting/mood: soft even studio light, calm, warm, emotionally safe.
Color palette: dark chocolate hair, warm medium-brown skin, golden-brown glasses, coral-orange shirt, muted teal trousers, cream shoes, soft yellow flower glow.
Constraints: preserve one exact character identity across every panel; identical hair shape, glasses, skin tone, body proportions, outfit and colors; strong readable silhouette at 56px; anatomically coherent hands; original character; no branding, no logo, no watermark.
Avoid: any text or labels, different outfits, extra accessories, extra characters, exaggerated anime features, huge sparkling eyes, childlike age, photorealism, 3D render, clay texture, painterly brushwork, inconsistent face or proportions.
```

## Avatar transparente

**Referência:** `model-sheet-v1.png`

```text
Use case: stylized-concept
Asset type: transparent floating mascot asset for a mobile wellness app UI
Input images: Image 1 is the canonical Alumia model sheet and is the strict identity reference.
Primary request: create one single isolated full-body Alumia chibi in a calm welcoming idle pose, facing three-quarter toward the viewer. Her right hand gives a small gentle wave and her left hand holds the same small glowing yellow flower from the model sheet. Both feet and the entire hair silhouette must be visible.
Subject: exact same adult feminine chibi character from the reference: warm medium-brown skin, fixed dark rounded curly bob silhouette, thick eyebrows, large round golden-brown glasses, coral-orange short-sleeve shirt, high-waisted muted teal trousers, warm cream sneakers, approximately 3 heads tall.
Style/medium: exact same clean premium 2D vector-like character rendering as the model sheet, rounded animation-ready shapes, restrained soft cel shading, crisp clean edges.
Composition/framing: one centered character only, full body, generous transparent margin around every edge, balanced upright pose, readable at 64px.
Scene/backdrop: genuinely transparent background with preserved alpha, no floor, no shadow rectangle, no scenery.
Lighting/mood: soft even light, calm, welcoming, emotionally safe.
Constraints: preserve the exact canonical identity, hair shape, facial proportions, glasses, outfit and colors from the model sheet; one character only; clean alpha edges; no text, no logo, no watermark.
Avoid: background color, panel, border, circle, square, other poses, extra limbs or fingers, different clothing, 3D clay style, painterly texture, childish baby proportions, exaggerated anime eyes.
```
